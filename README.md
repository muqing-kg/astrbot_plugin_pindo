# astrbot_plugin_pindo

拼豆图纸生成器 AstrBot 插件：聊天中发送图片，机器人返回带色号与用量统计的拼豆图纸 PNG；同时内置可对外访问的 Pindo 网页版 WebUI。

引擎移植自开源项目 [LunarXuan/Pindo](https://github.com/LunarXuan/Pindo)（GPL-3.0），本插件为该项目的衍生作品，依据 GPL-3.0 同样以 GPL-3.0 开源发布。

## 使用

| 命令 | 说明 |
| --- | --- |
| `拼豆` 或 `/拼豆` | 用默认品牌（MARD）把图片转成图纸 |
| `拼豆 MARD` | 指定品牌（支持序号、品牌名大小写不敏感、`artkal` 简写） |
| `拼豆品牌方` | 列出全部 8 个品牌（带序号） |

- 收图优先级：消息内图片 > 引用图 > 被 @ 用户的 QQ 头像（仅 QQ 平台；只有消息中 @ 了某位用户才读取其头像，未 @ 时不读取）。
- 三者皆无时会提示在 30 秒内补发图片，「撤销」取消，超时静默结束；只认发起人本人的消息，多张图片只取第一张。
- 图纸不锁定比例：默认宽 35 颗、高按原图比例换算，任意一边超过 120 颗时等比压缩到 120。
- 输出为一张 PNG：网格、每 5 格中粗线、每 29 格拼板粗线、蓝紫色外框、底部圆角色块用量图例「色号（数量）」，最底部为信息条（机器人名 · 品牌 ｜ 尺寸 ｜ 总颗数）。
- 处理参数与 Pindo 网页默认一致：写实模式、平均池化、无抖动、白底、最多 16 色（CIEDE2000 关键色保护限色）。
- 回复经 `event.send(MessageChain)` 直发：不引用原消息、不附加 @，绕过框架结果装饰管线与其他插件的 `on_decorating_result` 钩子；发送后 `stop_event()` 隔离后续插件与 LLM 兜底。

## Web 网站部署指南

插件自带一个完整的拼豆图纸生成网站（Pindo 网页版），由插件内置的轻量 HTTP 服务托管，**安装插件后自动启动，无需额外安装任何组件**。网站为纯静态应用，所有图像处理均在浏览器本地完成，不上传、不存储任何用户数据。

### 一、快速开始

1. 安装并重载插件，日志中出现以下字样即代表网站已启动：
   ```
   Pindo WebUI 已启动: http://0.0.0.0:8765
   ```
2. 浏览器访问 `http://<服务器IP>:8765`。
3. 云服务器（甲骨文/阿里云/腾讯云等）需在控制台**安全组/安全列表**放行 8765 端口（入方向 TCP）。

### 二、网站相关配置

以下配置均位于 AstrBot WebUI → 插件管理 → 本插件 → 配置，**修改后需重载插件生效**：

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `enable_site` | `true` | 是否启动内置网站；不需要时关闭可少占一个端口 |
| `site_host` | `0.0.0.0` | 监听地址；`0.0.0.0` 对外开放，仅本机使用改为 `127.0.0.1` |
| `site_port` | `8765` | 监听端口；被占用时服务会自动重试 3 次后放弃，请换端口 |
| `site_title` | 空 | 网站标题，作用于浏览器页签与页面大标题；留空为默认标题 |
| `site_logo` | 空 | 网站图标图片直链；留空使用插件内置图标，填写后替换页签 favicon 与标题旁图标 |
| `site_url` | 空 | 网站的**对外访问地址**，用于聊天出图时的引导文案 |
| `send_site_hint` | `false` | 开启后，机器人出图会在同一条消息附带下方自定义文字 |

### 三、自定义标题与图标

- **标题**：`site_title` 填写如 `沐倾的拼豆小站`，浏览器页签与页面大标题同步替换。
- **图标**：`site_logo` 填写一张图片的直链（以图片文件结尾的 URL 最佳），页签 favicon 与标题旁圆标同步替换。
- 若改完没变化：先重载插件，再强制刷新浏览器（`Ctrl+F5`）——浏览器对 favicon 有独立缓存。

### 四、对外提供访问

**方式 A：直接暴露端口（最简单）**

放行端口后直接使用 `http://公网IP:8765`。缺点是 HTTP 明文且无域名。

**方式 B：反向代理 + 域名 + HTTPS（推荐）**

已有域名时，用任意一种反向代理将域名转发到 `127.0.0.1:8765`（此时建议将 `site_host` 改回 `127.0.0.1`，仅监听本机，由反代对外）：

nginx：

```nginx
server {
    listen 80;
    server_name pindou.example.com;
    location / {
        proxy_pass http://127.0.0.1:8765;
        proxy_set_header Host $host;
    }
}
```

Caddy（自动签发 HTTPS 证书）：

```caddy
pindou.example.com {
    reverse_proxy 127.0.0.1:8765
}
```

1Panel 用户：网站 → 创建网站 → 反向代理，代理地址填 `http://127.0.0.1:8765`。

### 五、将对外地址回填给机器人

网站可访问后：

1. 把最终地址（如 `https://pindou.example.com`）填入 `site_url`；
2. 打开 `send_site_hint`，并在 `site_hint_text` 中自定义文案，占位符 `{url}` 会替换为该地址；
3. 重载插件。此后机器人每次出图都会在同一条消息里附带引导文字，例如：

> 完整功能请前往 https://pindou.example.com

### 六、常见问题

- **访问白屏 / 资源 404**：确认重载插件后日志中有「Pindo WebUI 已启动」，且未改动 `webui` 目录内容。
- **端口被占用**：日志会提示重试与放弃，更换 `site_port` 后重载。
- **不想要网站对外暴露**：`enable_site` 关闭，或 `site_host` 改为 `127.0.0.1` 仅本机访问。
- **安全说明**：网站为纯静态展示应用，无登录体系也无数据接口；如部署在公网且介意被扫描，建议通过反代加一层访问控制。

## 安装

将本仓库克隆到 AstrBot 的 `data/plugins/astrbot_plugin_pindo`，或在 WebUI 插件页从本地上传安装，随后重载插件。依赖仅 `numpy`（Pillow、aiohttp 均为 AstrBot 框架自带）。

## 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `default_brand` | `MARD` | 默认品牌色板（显示名：MARD/COCO/漫漫/盼盼/咪小窝/Hama/Perler/Artkal S） |
| `robot_watermark` | 空 | 图纸底部信息条的机器人名，留空不显示 |
| `wait_timeout` | `30` | 补图等待秒数，超时静默 |
| `max_long_edge` | `120` | 图纸最长边颗数上限 |
| `enable_site` | `true` | 是否启用内置 WebUI |
| `site_host` / `site_port` | `0.0.0.0` / `8765` | WebUI 监听地址与端口 |
| `site_title` | 空 | 网站标题（页签与页面大标题），留空用默认「Pindo 拼豆图纸生成器」 |
| `site_logo` | 空 | 自定义网站 Logo 图片链接（页签 favicon 与标题旁图标），留空用内置插件图标 |
| `site_url` | 空 | WebUI 外部访问地址；供附带文字的 `{url}` 占位符替换 |
| `send_site_hint` | `false` | 出图时附带下方自定义文字（渲染后为空则不发送） |
| `site_hint_text` | `完整功能请前往 {url}` | 出图附带文字模板，`{url}` 替换为外部访问地址，不含占位符则原样发送 |

## 开发自检

仓库根目录 `test_core.py` 为引擎自检：核心不变量断言 + 与 Pindo 原版 TypeScript 引擎的对拍（需环境变量 `PINDO_REPO` 指向 Pindo 检出目录、本机装有 Node ≥22.6）：

```bash
PINDO_REPO=/path/to/Pindo python test_core.py
```
